# PROJECT SYSTEM TEMPLATE
> Use this every time you start a new project. Fill each section before you build anything.

---

## 1. PROJECT BRIEF

```
Project Name:
Problem it solves:
Who it is for:
Why it matters:
Expected result:
```

---

## 2. OFFER / OUTCOME

```
Main promise:
Before state (client/user pain):
After state (what life looks like):
What they get:
Why they should care:
```

---

## 3. MEMORY / KNOWLEDGE BASE

Files in this project:
- brief.md         → Project brief & context
- client-or-user.md → Who you are building for
- offer.md         → The core offer and promise
- research.md      → Market, competitor, audience notes
- scripts.md       → Prompts, copy, messages, scripts
- assets.md        → Links to files, images, tools
- decisions.md     → Every major decision logged
- tasks.md         → Current task list
- automations.md   → What runs automatically
- launch.md        → Launch checklist and go-live plan

---

## 4. SKILLS SYSTEM

| ID       | Skill Name         | Purpose                          |
|----------|--------------------|----------------------------------|
| skill_01 | research           | Gather info on topic or market   |
| skill_02 | lead-finder        | Identify potential clients       |
| skill_03 | outreach-message   | Write first contact message      |
| skill_04 | content-generator  | Create posts, scripts, copy      |
| skill_05 | follow-up          | Nurture leads / responses        |
| skill_06 | booking-handler    | Confirm + manage bookings        |
| skill_07 | report-generator   | Weekly summary of results        |

**Each skill uses this format:**
```
Skill Name:
Purpose:
Input:
Process:
Output:
Tool Used:
Success Criteria:
```

---

## 5. AUTOMATION LAYER

```
Automation:
Trigger:
Action:
Tool:
Output:
Frequency:
Human approval needed? Yes / No
```

**Common automations:**
- New lead added → generate outreach message
- Client replies → classify response
- Booking confirmed → send confirmation
- Weekly → generate performance report

## 7. EXECUTION PHASES

| Phase | Name      | Goal                              |
|-------|-----------|-----------------------------------|
| 1     | Define    | Clarify the idea and outcome      |
| 2     | Build MVP | Smallest working version          |
| 3     | Test      | Validate with real users          |
| 4     | Improve   | Fix gaps, add feedback            |
| 5     | Launch    | Go live officially                |
| 6     | Automate  | Remove manual steps               |
| 7     | Scale     | Grow without adding more effort   |
